一、作品名称

薄肌计划 BojiPlan

名字由来：项目起点是孙宇晨 × 邵艾伦那场 5 小时访谈里的一套「网红理论体系」——薄肌（身体底层资产）、搏击（动态神经资产）、大水、大睡、先开图再出兵、先自由后财富、少消费多创造。我们把这套只存在于切片视频里的认知，产品化成一个真正每天在用的 Agent。

二、核心功能

💬 AI 掌舵对话

背后是真实大模型（默认 step-5-preview，模型列表动态拉取）。系统提示词持续注入记忆/身体/健康/今日数据——它真的认识你。问到时效性问题自主调用 StepSearch，末尾附来源卡片。流式输出，思维链实时可见。

📊 每日打卡与碳基服务器

饮水/睡眠/搏击/薄肌/创造五类打卡，四个指标环 + AI 掌舵日报（按数据差距给行动建议）+ 服务器负载率 + 近 7 日睡眠图。

🩺 健康模块

上传体检报告（拍照/相册）→ AI 视觉通读 → 身体状况总结 + 异常/疾病清单（名称/系统/等级/指标）。身体数据快照：身高/体重/体脂，自动 BMI 分级，双轴曲线，历史可编辑。

💰 资产模块

只记「某一时刻的总资产/总负债」两个数字，三条曲线（总资产/总负债/净资产）按快照时间绘制，支持编辑任意历史快照。

🗓️ 一周训练计划（招牌）

先输入器械条件 → AI 结合身体数据 + 薄肌目标 + 搏击/大睡理论生成 7 天计划，详细到组数×次数、组间休息秒数、退阶选项。器械硬约束：无搏击条件绝不排搏击。生成后固定，默认折叠，可编辑。

🧠 记忆页 + ⏳ 生命倒计时

长期记忆库（分类/搜索）、饮食记录（自动带时间）、备忘录（待办勾选）。我的页：生日 + 预期寿命 → 剩余天数 + 时:分:秒秒级跳动 + 人生进度条。

三、技术方案与实现思路

3.1 整体架构

┌──────────────────────────────────────────────┐ │ 安卓 App（WebView 壳，Gradle 工程） │ │ WebViewAssetLoader → https://appassets... │ │ └── 单文件 Web App（HTML/CSS/JS，零依赖） │ └──────────────┬───────────────────────────────┘ │ HTTPS（已实测 api.stepfun.com 允许浏览器跨域） ▼ ┌──────────────────────────────────────────────┐ │ StepFun 开放平台（OpenAI 兼容） │ │ · /v1/chat/completions 对话/计划生成/视觉理解 │ │ · /v1/search StepSearch 联网搜索 │ │ · /v1/models 动态模型列表 │ └──────────────────────────────────────────────┘ 数据持久化：localStorage（全在本机，零后端）

为什么零后端：个人 Agent 的敏感数据（体检报告、资产、健康）不应出本机；StepFun API 允许跨域直连，使纯前端方案成立。安卓壳只做容器（文件选择/拍照/返回键），业务逻辑全在 Web 层，改网页一条命令重新出包。

3.2 AI 掌舵 = 系统提示词工程

每次请求动态组装六层上下文：① 机器人身份与人设 ② 理论底座（搏击/大水/大睡/先开图再出兵/先自由后财富/少消费多创造）③ 用户资料 ④ 今日实时数据 ⑤ 长期记忆（最近 25 条）⑥ 健康档案 + 最新身体快照。再加两条行为规则：长期记忆提炼协议与联网搜索触发规则（时效性问题才检索，打卡闲聊不检索，避免浪费 token 和延迟）。

3.3 自研轻量「AI 结构化输出协议」

让模型以约定标记行输出结构化数据，前端解析后自动入库、标记不展示给用户：

标记用途现状
[[MEMORY:分类|内容]]对话中提炼长期记忆（职业/目标/习惯/偏好/关系/决定）已启用默认开，可关
[[BODY:身高|体重|体脂]]自动记身体快照已关闭（改手动，防误记）
[[SNAPSHOT:资产|负债]]自动记资产快照已关闭（改手动，防误记）

价值：不用向量数据库、不用后端，靠「系统提示 + 标记协议 + 前端解析」实现 Agent 持久记忆，去重、分类、展示全部本地完成。

3.4 Function Calling：StepSearch 工具循环

官方文档明确 step-5-preview 不支持 Chat Completions 内置 web_search 工具类型，推荐把 /v1/search 封装成自定义 function 工具。我们实现了完整的迷你 Agent 循环：

第 1 轮请求（带 tools 定义）
  → 模型返回 tool_calls{query}
  → App 显示「🔍 正在联网搜索」并请求 /v1/search
  → 结果作为 tool 消息追加进 messages
第 2 轮请求（不带 tools，防循环）
  → 模型基于真实检索结果流式回答 + 来源卡片

流式场景下 tool_calls 按 index 分片到达，写了增量累加解析；失败时把错误作为 tool 结果回传，模型自然降级回答，不会卡死。

3.5 多模态：体检报告视觉解读

相册/拍照 → canvas 压缩到 1600px JPEG → image_url 多部分消息 → 要求只输出 JSON（summary + items）。解析四层容错：剥离代码块 → 首尾大括号切片 → JSON.parse → 散文/markdown 兜底解析，外加失败自动重试一次。

3.6 对推理模型的工程适配（踩坑全集）

问题现象解法
思维链吃 token设 max_tokens 会截断回答/返回空不设 max_tokens（官方默认 INF）
生成等待久且无反馈10 分钟不知道卡没卡全链路流式：思维链 💭 与正文分开滚动 + 秒数/字符数 + 45s 提示 + 可取消
结构化任务想太久计划生成动辄数分钟reasoning_effort: low（400 不支持自动去参重试）
连通性测试误判小 max_tokens 被思维链吃光返回空探针 max_tokens: 1，HTTP 200 即成功
输出被截断JSON 不完整解析失败去上限 + 自动重试 + 兜底解析

3.7 图表全部手写 SVG

指标环、近 7 日睡眠柱状图、资产三线曲线、身体数据双轴曲线（左轴 kg / 右轴 %）、人生进度条——零图表库，直接生成 SVG path，单文件交付。

3.8 安卓壳关键实现

  • WebViewAssetLoader 把 assets 以 https://appassets.androidplatform.net/ 提供（合法 https origin，canvas/存储全正常，避开 file:// 的坑）
  • onShowFileChooser 实现相册 + 拍照（FileProvider 授权，运行时申请相机权限）
  • 系统返回键先问页面（window.__bojiBack 关弹窗），再走 WebView 历史
  • UA 追加 BojiPlanApp，网页自动隐藏模拟状态栏融入真机
  • Gradle 8.7 + AGP 8.5.2 + JDK 17 + SDK 34，minSdk 26

四、作品创新点

1. 「访谈理论产品化」

不复制又一个聊天机器人，而是把一套具体的认知体系变成每日可执行的打卡、计划和决策框架——理论直接约束 AI 输出（如"没有搏击条件就绝不排搏击"）。

2. 零基础设施的 Agent 长期记忆

不用向量库/后端，用「系统提示注入 + 标记协议 + 前端解析」实现持久记忆与自动提炼，个人敏感数据全留本机。

3. 器械约束的计划生成

生成前先采集用户实际器械条件并写入硬性约束，解决"AI 计划很美但没法执行"的经典问题；计划详细到组数×次数+组间休息秒数+退阶选项，默认折叠只显示概要。

4. 快照式资产管理

拒绝流水账，只记"某一时刻的总资产/总负债"，用三线曲线看净值演变——更贴合个人真实管理习惯。

5. 生命倒计时作为产品骨架

预期寿命设定 + 天/秒级倒计时 + 人生进度条，把"时间有限"变成使用产品的底层驱动，与"先自由后财富"形成呼应。

6. 推理模型的完整工程适配

流式思维链可视化、思考强度分场景调控、探针式连通性测试、截断容错、参数回退——这套经验可直接复用到任何基于 Step 推理模型的应用。

7. 单文件零依赖 + 安卓壳

整个业务是一个 HTML 文件，改完一条命令出 APK，交付和迭代成本极低。

六、路演演示脚本（建议 5 分钟）

  1. 开场（30s）：展示生命倒计时——"你的 AI 知道你还能自由支配多少天"。
  2. 理论落地（1min）：掌舵页打卡 + AI 日报："它按搏击理论和大睡理论给我今天的建议"。
  3. 招牌功能（2min）：训练计划生成——先填器械（"无搏击条件"）→ 看思维链滚动 → 30 秒拿到写到组间休息秒数的 7 天计划 → 点开周二展开动作 → 手动改一个动作。
  4. 多模态（45s）：上传一张体检报告照片 → AI 输出疾病清单和分级。
  5. 联网搜索（30s）：问一个今天的新闻 → 看它自己决定搜索 → 附来源回答。
  6. 收尾（15s）：资产三线曲线 + "数据全在你手机里，零后端"。

七、数据与隐私

  • 所有个人数据（API Key、记忆、打卡、体检、资产、身体、计划）仅存于设备 localStorage / WebView 本地存储
  • 无自建服务器、无数据上报；卸载即清除
  • API Key 由用户自行在 StepFun 开放平台创建，直连官方接口
